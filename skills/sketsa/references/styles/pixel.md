# Style: pixel

pixel (8/16-bit)

Chunky pixel-art sprite aesthetic, limited palette, visible square grid,
hard edges — no anti-aliasing, no gradients, no soft shadows. The mascot is
a readable sprite (silhouette first); the scene is built from a few large
pixel shapes. Dithering allowed sparingly.
