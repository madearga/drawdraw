# Style: blueprint

blueprint (technical drawing)

Schematic look: white/light-blue drafting paper, fine cyan-blue linework,
dashed measure lines, small annotation marks. The mascot is drawn with the
same linework plus one warm accent (orange/red) so it stays the focal
point. No fills heavier than a flat tint; hatching instead of shading.
