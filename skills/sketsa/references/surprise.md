# Surprise me

When the user says `/sketsa surprise` (or "surprise me"), you pick the
idea — not a random dictionary word, a **specific, relatable moment**.

## How to pick

1. Pick one row from two different tables below at random.
2. Fuse them into one sentence: "<emotion> of <concept>".
3. If the fusion is stale ("stress of deadlines"), re-roll once — the bar
   is a moment a developer would screenshot and send to a coworker.

## Emotion moments

the 2am relief · the smug one-liner commit · the dread of a clean build
failing locally · the quiet pride of a renamed variable · the panic of
"who deployed this" · the joy of deleting 200 lines · the fear of the
migration running on prod · the patience of watching tests crawl

## Concepts

caching · rollbacks · code review comments · flaky tests · rubber-duck
debugging · dependency upgrades · dark mode launch · rate limits ·
backups nobody tested · feature flags · on-call handoff · n+1 queries

## Then

Run the normal pipeline (single shot, editorial layout, character's
default palette) and title the delivery line with the sentence you fused.
